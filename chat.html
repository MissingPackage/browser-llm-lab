modello

campionamento

temperature 0 = greedy: è l'argmax che il motore calcola già, riproducibile e confrontabile col golden. Sopra 0 si campiona in CPU dai logits di quello stesso step, col seed che finisce nell'export.

system prompt

Applicato solo al primo turno del contesto (poi la KV lo tiene). «Azzera» lo rende di nuovo effettivo.

export

Il JSON porta parametri di carico, campionamento con seed, prompt reso in ChatML con gli id, e le metriche per turno. Non è un riferimento: niente warm-up scartato, niente repliche, host non dichiarato.
